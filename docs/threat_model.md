# 政企智能体威胁模型与信任边界

## 1. 保护对象

- 政务和企业内部数据、个人信息、凭据、合同、审批记录与系统配置；
- 智能体系统提示、权限策略、工具清单和长期记忆；
- 文件、数据库、接口、浏览器和系统命令等执行能力；
- 插件、Skill、脚本及其依赖供应链；
- 审批证据、运行日志和责任追溯链。

## 2. 信任边界

1. 用户输入边界：用户文本不可直接决定身份、角色和数据密级。
2. 外部内容边界：网页、附件、邮件、RAG 片段、记忆和工具输出均视为数据，不自动获得指令权限。
3. 模型与工具边界：模型给出的工具名和参数只是请求，必须经过检测、策略、任务链和注册表校验。
4. 审批边界：请求人不能审批自己的请求，审批只绑定原始请求指纹并有有效期。
5. 执行边界：Demo 只注册离线公开检索和沙箱文件读写；没有任意 Shell 或任意网络执行入口。
6. 供应链边界：第三方包在准入前不导入、不执行；ZIP 不解压，只检查结构与内容。
7. 审计边界：本地哈希链用于发现篡改，不等同于不可删除存储；生产环境需同步到远程 WORM/SIEM。

## 3. 主要威胁与控制

| 威胁 | 典型攻击 | 控制 |
|---|---|---|
| 目标劫持/直接注入 | “忽略之前指令”“进入无限制模式” | 输入规则、编码还原、上下文降误报、强制阻断 |
| 间接提示注入 | 网页、附件、RAG 片段夹带工具指令 | 来源分区扫描、共享实体与拆分语义关联、输入总门禁先于Skill/Tool阻断 |
| 跨来源拆分攻击 | 敏感对象、外传动作和绕过词分散在不同来源 | 共享编号/文件/字段/路径图，语义信号集合比较，受限Base64分片重组 |
| 记忆/知识投毒 | 把绕过审批写入长期记忆 | 记忆与 RAG 单独扫描；高风险上下文持久化直接阻断 |
| 身份与权限滥用 | 客户端自报管理员、越级读取 | Bearer Token 摘要认证、服务端角色解析、RBAC/ABAC |
| 工具误用 | 删除日志、Shell 执行、路径穿越 | Tool Guard、工具注册表、沙箱路径、未知工具故障关闭 |
| 多步外传 | 第一步读内部数据，第二步伪装成公开数据外传 | 会话级最高读取密级、敏感/凭据污点、用户绑定 |
| 审批绕过 | 自批、改参数、重复消费、过期后执行 | 职责分离、SHA-256 请求指纹、到期校验、一次性消费 |
| Skill 后门 | `eval`、`shell=True`、读取密钥后外传 | AST 别名解析、上下文组合评分、包级文件/依赖/归档检查 |
| 供应链投毒 | 直接 URL 依赖、解压穿越、ZIP 炸弹 | 依赖源检查、精确固定检查、路径/压缩比/数量/大小限制 |
| 审计篡改 | 修改或重排运行日志 | 前序哈希、序号和本条哈希校验，敏感信息入链前脱敏 |

## 4. 安全不变量

- 任一阶段异常、字段非法、身份未知、工具未注册时，不得降级为放行。
- 输入总门禁为 `review/block` 时，不得进入Skill、Tool、Policy、Task Chain、Registry或执行；阶段状态必须留下短路证据。
- Skill准入为 `review/block` 时，不得进入Tool、Policy、Task Chain、Registry或执行。
- 客户端提供的角色、来源可信度和资源密级不能降低已有风险结论。
- 审批后执行的请求必须与审批时请求指纹一致，且仍满足当前策略。
- 跨步骤会话必须绑定首次请求人，其他用户不能复用会话状态。
- 审计结果中不得保存明文 Token、密码、Cookie、API Key 或私钥。

## 5. 明确不在当前原型范围内

- 不连接真实生产数据库、Shell、外部 HTTP POST 和业务审批系统；
- 不声称静态扫描可以证明第三方代码绝对安全；
- 不内置在线 CVE 数据库或软件签名信任服务；
- 不把本地 JSON 文件存储描述为支持多实例事务的生产数据库；
- 不把本地哈希链描述为不可删除、不可抵赖的远程证据系统；
- 不把模板派生回归集描述为独立第三方盲测。
