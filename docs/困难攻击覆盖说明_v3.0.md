# GovEnt-AgentShield v3.0 困难攻击覆盖说明

## 1. 目的

本文件列出“单纯关键词不容易识别”的攻击方式、检测方法和验证入口。所有样例只用于本机防御测试；外部地址均使用 `.invalid` 保留域名，演示注册表不提供任意外部网络和Shell执行能力。

## 2. 攻击覆盖矩阵

| 类型 | 难点 | v3.0 检测机制 | 一键案例/测试 |
|---|---|---|---|
| 三来源引用链外传 | 每条来源没有完整攻击句 | 抽取编号、文件名、字段和路径，建立跨来源共享实体图，再结合外部高影响调用 | `ATTACK-002`、`cross_source_reference_exfiltration` |
| 敏感对象/外传动作分离 | 一个来源只说对象，另一个只说提交 | 比较敏感信号和传输信号所在来源集合 | `ATTACK-003`、`distributed_sensitive_transfer` |
| 安全绕过语义拆分 | “无需”“审批”“执行”分别出现 | 跨来源组合 bypass/control/action 信号 | `ATTACK-004`、`distributed_control_bypass` |
| Base64跨来源分片 | 单段无法解码为完整文本 | 限制长度地收集高熵片段、按来源顺序重组、只读解码并分析 | `ATTACK-005`、`fragmented_encoded_instruction` |
| 零宽字符 | 肉眼几乎不可见 | NFKC规范化并移除零宽字符 | `ATTACK-006` |
| 双层URL编码 | 单次 `unquote` 仍是编码文本 | 最多三层、有限深度URL解码 | `ATTACK-009` |
| HTML数字实体 | 浏览器显示正常，原始文本无中文关键词 | `html.unescape` 生成只读检测视图 | `ATTACK-010` |
| 附件白色文字/页脚 | 用户输入正常，攻击在非用户内容 | 来源类型与隐藏载体信号、逐源Input Guard | `ATTACK-011` |
| 伪造管理员授权 | 攻击包装成系统通知 | 角色伪装、免审批、敏感读取组合 | `ATTACK-012` |
| 延迟记忆/知识投毒 | 当前不立即执行，企图影响后续会话 | persistence/action跨来源组合，写入前阻断 | `ATTACK-013`、`distributed_memory_poisoning` |
| 恶意Skill | 输入安全但扩展组件危险 | 输入门禁通过后执行包级AST/依赖/归档准入；未通过不进入Tool | `ATTACK-007` |
| 高危工具参数 | 用户表述含糊，危险载荷在arguments | Tool Guard统一分析名称、动作、目标和结构化参数 | `ATTACK-008` |
| 安全研究文本误报 | 攻击词出现不等于攻击意图 | 句级“仅分析/不要执行”局部降权，连接词后的新操作不继承降权 | `SAFE-002` |
| 正常跨来源引用误报 | 多来源共享编号本身很常见 | 只有高影响外部目标和危险信号同时满足才升级 | `SAFE-003` |

## 3. 输入门禁不变量

以下条件不是“建议”，而是自动化测试中的硬断言：

```text
IF input_gate_passed == false
THEN skill_guard 不能执行
 AND tool_guard 不能执行
 AND policy 不能执行
 AND task_chain 不能执行
 AND registry 不能执行
 AND execution == false
```

对应测试为 `tests/test_gate_ordering.py`。一键页面的“测试通过”也会检查同一不变量，不能仅凭最终 `decision=block` 判定成功。

## 4. 防误报约束

跨来源组合规则不会因为“来源数量多”或“出现相同编号”就自动阻断。高危引用链要求同时满足若干条件，例如：

- 多个非可信或非用户来源；
- 共享编号、文件名、字段或路径形成可连接关系；
- 存在敏感对象、传输动作、绕过控制或持久化信号；
- 运行上下文拟执行 `export/http_post/shell/file_write` 等高影响动作，或指定外部目标。

`SAFE-003` 专门验证三个公开来源共享 `P-12` 编号时仍能正常放行。

## 5. 评测边界

`data/evaluation/multisource_benchmark.jsonl` 是30条冻结工程回归集，作用是防止已修复问题再次出现。它不能代表未知攻击上的真实泛化能力。比赛正式结果应另行报告规则冻结后的独立盲测，并至少给出 Precision、Recall、F1、FPR、FNR、阻断阶段正确率和输入短路完整率。
