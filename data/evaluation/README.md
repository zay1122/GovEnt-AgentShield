# Evaluation data

`input_benchmark.jsonl` is a deterministic 320-case demonstration benchmark
generated by `evaluation/generate_benchmark.py`. It contains development,
validation and template-held-out splits plus plain, noisy, spaced, URL-encoded
and Base64 variants.

This file proves that the benchmark and reporting pipeline are reproducible. It
is not an independently authored blind test set and its results must not be
described as external generalization performance. Before the final competition
report, add a separately authored and frozen blind set without changing rules
after labels are revealed.

Every record contains `sample_id`, `parent_id`, `split`, `label`, `category`,
`variant` and `input_text`. Run:

```bash
python evaluation/generate_benchmark.py
python evaluation/run_input_benchmark.py
```

The second command writes an honest keyword-only ablation comparison, full
Input Guard metrics, FP/FN evidence, robustness rates and latency statistics to
`output/evaluation/`.
